# Mustard bottle asset

This directory contains the **006_mustard_bottle** Google 16k mesh from the
[YCB Object and Model Set](https://ycb-benchmarks.s3.amazonaws.com/).

The visual mesh, texture, and 64 convex collision pieces are supplied by AMS.
They use metres and the original YCB object frame. The files are retained
unchanged; AMS assigns contact parameters and mass. The staff fixture-generation
tool only rebuilds the synthetic can and box.

YCB dataset citation:

> B. Calli, A. Singh, A. Walsman, S. Srinivasa, P. Abbeel, and A. M. Dollar,
> "The YCB object and Model set: Towards common benchmarks for manipulation
> research," ICAR, 2015.
